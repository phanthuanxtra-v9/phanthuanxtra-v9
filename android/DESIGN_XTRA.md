# PHAN THUẦN XTRA — Premium Android Design System

## Direction
Inspired by the product discipline of Tesla and the bold, precise visual language of Automobili Lamborghini, without copying either brand. The XTRA identity is **black + champagne gold + emerald jade**, with automotive photography and restrained motion.

Lamborghini's current corporate identity explicitly reconfirms black/white as primary hues and yellow/gold as accents; its design DNA emphasizes precise lines, clean surfaces, and hexagon/Y geometry. Tesla's mobile product emphasizes direct vehicle access and remote monitoring. XTRA should translate those principles into a dealership operations cockpit: fast, clear, premium, operational.

## Palette
- XTRA Black: `#050505` — primary background
- Carbon: `#101214` — elevated surfaces
- Graphite: `#1A1D20` — cards/input surfaces
- Champagne Gold: `#D4AF37` — primary actions, key metrics, active focus
- Gold Soft: `#E7C968` — labels/highlights
- Jade Emerald: `#00A884` — success, connected, AI/live status
- Deep Jade: `#006B57` — pressed/secondary state
- Ice White: `#F4F5F2` — primary text
- Silver: `#A9AFB5` — secondary text
- Danger: `#E85D5D` — destructive/error only

## UX rules
1. Dark canvas first; avoid generic Material purple/blue defaults.
2. Gold is scarce: primary CTA, important totals, active navigation.
3. Emerald means live/healthy/AI/success, never decoration.
4. Large automotive imagery; text stays sparse.
5. Prefer 8–16dp spacing and 12–16dp card corners; buttons can be 10–12dp radius for touch comfort.
6. Use uppercase micro-labels with generous letter spacing for premium metadata.
7. Dashboard hierarchy: system status → inventory/value → leads → AI intake → quick actions.
8. Bottom navigation: Dashboard / Kho xe / Leads / AI. Settings and credentials live in a protected Operator area.
9. Every destructive action requires explicit confirmation.
10. Token screens must never reveal token values by default and must never inject credentials into WebView/chat.

## Motion
- 160–220ms transitions for navigation and state changes.
- Subtle fade/slide only; no gratuitous parallax.
- Emerald pulse may indicate live connectivity/AI processing.

## XTRA signature
Use a thin gold rule plus a small emerald status marker as the recurring visual motif. Do not use Lamborghini logos, typefaces, proprietary graphics, or copied layouts.
