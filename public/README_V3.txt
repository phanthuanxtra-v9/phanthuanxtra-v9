AUTO XUYÊN Á V3 – SECURITY EDITION
Upload-ready for Cloudflare Pages Direct Upload.

NÂNG CẤP V3:
- Đã thay toàn bộ example.com bằng phanthuanxtra.com.
- HTTPS canonical, robots.txt và sitemap.xml đúng domain.
- CSP không cho inline JavaScript/CSS và chặn object/frame injection.
- X-Frame-Options DENY, nosniff, Referrer-Policy, Permissions-Policy.
- COOP/CORP và HSTS.
- Cache-Control cho HTML/CSS/JS/data.
- 404.html, favicon.svg, webmanifest và security.txt.
- Mobile navigation có accessible controls.
- Search/filter dữ liệu kho xe có escaping HTML.
- Không PHP, WordPress, database public, plugin hoặc API key.
- Không có form public nên giảm đáng kể bề mặt spam/abuse.

TRƯỚC KHI PUBLIC:
1. Thay 08 6699 7891 và link Zalo bằng thông tin thật.
2. Thay các khối nền xe bằng ảnh xe thật (WebP/AVIF) nếu cần.
3. Xác nhận domain phanthuanxtra.com đã trỏ nameserver về Cloudflare trước khi gắn custom domain.
4. Kiểm tra HTTPS sau deployment.
5. Không đưa mật khẩu, API key, token hoặc dữ liệu khách hàng vào ZIP.

LƯU Ý:
Bản V3 là website tĩnh. Nếu cần quản trị xe bằng giao diện đăng nhập, không nên tự thêm PHP/admin vào Pages; nên thiết kế kiến trúc backend riêng với xác thực và secrets quản lý phía server.
