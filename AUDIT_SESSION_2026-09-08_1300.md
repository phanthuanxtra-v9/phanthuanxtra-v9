## Security invariant
Secret values are never written to the backup. Binding metadata is retained; sensitive fields such as secret/text/token/private-key values are redacted.

## Telegram delivery
The backup workflow sends a status message, manifest, and SHA-256 file to the dedicated backup chat. The full archive is also uploaded when it is below a conservative 49,000,000-byte threshold; otherwise the complete archive remains available as the GitHub Actions artifact for the configured retention period. Telegram Bot API currently limits multipart document uploads to 50 MB.
